- 새 Azure 인프라 생성, 실제 테넌트 권한 변경, 모델 과금 호출, 앱 카탈로그 재게시 및 Teams/Copilot 대화는 이번 공개 작업에서 수행하지 않았습니다.

재실행할 명령과 단계별 완료 기준은 [README](../README.md)에 있습니다. 로컬 검사 성공과 클라우드 권한/정책 성공을 동일시하지 않습니다.

2026-10-28~29의 기존 데모 기록을 익명화해 요약합니다. 해당 결과가 새 실습 테넌트에 자동 적용되지는 않습니다.

## 코드에서 보완한 정책 처리

기존 데모 작업에서 Purview applicationLocation에 채널 ID 대신 명시적 Blueprint ID를 우선하도록 수정했습니다. 호환 프록시는 허용된 `Prefer: evaluateInline`을 전달하고, processingErrors 또는 명시적 inline 요청의 미완료/유효하지 않은 응답에 대해 모델 진행을 중단하도록 보완했습니다. 정상 allow/block 및 감사 경로를 회귀 테스트로 구분합니다.

민감정보 탐지는 정책의 방향·신뢰도·보조 단어 등에 영향을 받습니다. 특정 합성 입력 차단이 모든 숫자 형식·모든 채널·모든 정책의 차단을 보장하지 않습니다. 예전 요청의 정확한 실패 원인을 소급 확정하지 않습니다.
