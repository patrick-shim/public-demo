# 회사 정보 에이전트 시연 가이드

먼저 [검증 범위](validation.md)를 확인하고 실제로 응답이 확인된 채널에서 시연합니다. 이전 환경에서는 Teams 오류가 미해결이어서 Web Chat을 사용했습니다. 이를 Teams/Copilot 대화 성공으로 소개하지 않습니다.

| 순서 | 질문 예시 | 확인할 것 |
|---|---|---|
| 1 | LG에너지솔루션의 주요 사업과 제품을 공식 자료 기준으로 알려 줘. | 공식 회사 소개 출처 |
| 2 | Please summarize that in English. | 언어 전환과 대화 맥락 |
| 3 | 최근 30일 뉴스를 요약하고 회사 발표와 외부 보도를 구분해 줘. | 날짜·링크, GDELT 실패 시 부분 결과 안내 |
| 4 | 최근 실적 기사를 찾아 본문에 나온 숫자만 요약해 줘. | articleId 본문 조회, 분기·단위·잠정/확정 구분 |
| 5 | 2026년 공식 IR 자료 링크를 찾아 줘. | PDF 원문 링크. 본문을 읽었다는 주장 금지 |
| 6 | 주가와 통화, 기준 시각, 출처를 알려 줘. | KOSPI 373220, KRW, 지연 가능성·오래된 자료 표시 |

Purview 시연에서는 일반 질문을 먼저 확인한 뒤 테넌트에서 승인한 **합성 테스트 자료**를 사용합니다. 실제 고객 개인정보·카드번호·기밀을 입력하지 않습니다. 입력 차단과 출력 차단은 다른 규칙입니다. 원래 환경에서 확인한 것은 일부 입력 차단이며 새 환경에서는 직접 재검증해야 합니다.

Teams와 Copilot은 각각 로그인/답변을 확인합니다. 앱 게시와 사용자 설치만 성공했다고 대화까지 성공한 것으로 설명하지 마세요. 관리 화면에서는 게시자, Owner/Sponsor, 실행 신원, 정책, 관측 수집을 구분합니다.

자주 받는 질문:

- **무료인가요?** 공개 자료 API 키는 없지만 Azure 실행·모델·라이선스 비용은 별도입니다.
- **실시간 주가인가요?** 회사 IR에 표시된 시점의 스냅샷입니다.
- **PDF 내용을 요약하나요?** 현재는 링크만 제공하며 본문 추출은 하지 않습니다.
- **메일 계정이 필요한가요?** 이 OBO 데모는 전용 Agent User/메일함을 구성하지 않습니다.
- **포털 지침이 비어 있나요?** 실행 지침은 C# 코드에 있으며 포털 메타데이터와 별도입니다.
